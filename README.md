# 📜 CivSim — Advanced Civilization Simulator & Telemetry Hub

An advanced, multi-stratified generative civilization engine designed to simulate procedural world maps, spatial coordinates tracking, economic feedback loops, and live geopolitical updates.

## 📂 System Package Topography
```bash
your_project_directory/          # Root GitHub Repository Workspace
├── main.py                     # Root multi-threaded Flask network server
├── launch.bat                  # 1-Click Windows automation startup shell script
├── compile_mechanics.py        # Structural gameplay features compiler
└── civsim/                     # Core simulation engine package folder
    ├── __init__.py             # Package marker hook
    ├── world.py                # Ecosystem matrices & map layers
    ├── simulation.py           # Tick step sequence manager
    ├── civisim_GUI.py          # High-speed volatile RAM telemetry data mapper
    └── dashboard.html          # High-contrast macro management interface panel
```

## 🚀 Core Architectural Milestones (Phases 1-4 Complete)
*   **In-Memory RAM Volatile Buffering:** Shifted the data pipeline from heavy hard drive I/O writes to an in-memory queue cache (`collections.deque`), cutting telemetry latency from 80ms to under 1ms.
*   **Proportional 100×100 Canvas Multipliers:** Auto-stretches your simulation's true spatial coordinates evenly across a centered HTML5 Canvas grid equipped with center-focused camera zoom lenses.
*   **Deep Data Settlement Inspector:** Async network query endpoint tracking citizen population aggregations, public treasuries, and citadel fortresses in real-time.
*   **The Commodity Ticker Market & Guilds:** Real-time commodity matrix tracking market values (Grain, Iron Ore, Weapons, Mithril) driven by emergent trade guilds and production flows.
*   **Emergent Governance:** Republics, Monarchies, and Councils form dynamically based on population density, state capacity, and leadership metrics.
*   **Directed Causal Graphs:** Tracks history as an interconnected tree graph of cause and effect, enabling step-back logging diagnostics.
